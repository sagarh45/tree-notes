# Trees Lab — Unit IV Complete Package

Same layout as the Stack / Queue / Linked List labs: **Theory · Visualizer · Programs · Practice**.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:4321](http://localhost:4321).

## What’s inside

| Tab | What you get |
| --- | --- |
| Home | Eight models, eight jobs |
| Theory | 26 sections: core exam notes + advanced models (heap, RB, Huffman, trie, threads, B+, reconstruction). Every model has a Law, a Trap, and a drawing |
| Visualizer | **Core:** Traversals (live call-stack), BST, AVL, B-Tree. **Advanced:** Heap (tree+array), Red-Black, Huffman forest, Trie |
| Programs | C programs — copy and run on OneCompiler. Keys from scanf |
| Practice | MCQ, True/False, fill-in-the-blanks + cheatsheet including advanced traps |

Keyboard in the lab: Space play/pause, arrows step, I insert, S search, D delete/extract, R reset.
