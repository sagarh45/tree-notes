# Trees Lab — Unit IV Complete Package

Same layout as the Stack / Queue / Linked List labs: **Theory · Visualizer · Programs · Practice**.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:4321](http://localhost:4321).

## What’s inside

| Tab | What you get |
| --- | --- |
| Home | Learning path for the whole Trees unit |
| Theory | 15 exam-ready sections (definition → BST delete → AVL letters → B-Tree split) |
| Visualizer | Traversals, BST, AVL, B-Tree with step playback, C/pseudocode highlight, variables, history |
| Programs | 10 C programs — copy and run on OneCompiler |
| Practice | MCQ, True/False, fill-in-the-blanks + cheatsheet |

Keyboard in the lab: Space play/pause, arrows step, I insert, S search, D delete, R reset.
